# STI Information Assistant Prototype

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
1. Put `app.py` and `requirements.txt` in a GitHub repository.
2. Open Streamlit Community Cloud.
3. Select the repository and `app.py`.
4. Deploy.

This is an educational prototype, not a diagnostic system. Do not store identifiable patient data in the repository or app logs.
